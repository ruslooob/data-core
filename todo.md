## Новые инструменты

### Виджет фильтра событий
- Центральный источник событий для логической группы
- SQL-подобный запрос (DSL) + ручная корректировка чекбоксами
- Спека: `docs/SPEC_EVENT_FILTER.md`

### Язык поиска прецедентов (PQL) — пост-MVP расширения
- **Пользовательские функции** (`CREATE FUNCTION ... LANGUAGE SQL`): аналитик задаёт свои композиции метрик и порогов и сохраняет их между сессиями. Базовая фича для дальнейшего расширения языка.
- Дополнительные встроенные метрики: `drawdown`, `post_event_drift` и т.п. — методы соответствующих поставщиков по аналогии с `vol_ratio`/`volume_ratio`.
- Параметры расчёта на уровне запроса (общие значения окна, модели и т.п.) — пока задаются только аргументами `car()`.
- Интеграция с логической группой виджетов: трансляция результатов поиска.
- Подсветка строки/колонки в textarea при ошибке (требует структурированной позиции от движка SQL — DuckDB пока её надёжно не отдаёт).
- Спека: `docs/SPEC_PRECEDENT_LANGUAGE.md`.

### Прове��ка устойчивости (Robustness Check)
- Тепловая карта: средний CAR по набору событий × вариации параметров (окно, модель)
- Отвечает на вопрос: устойчив ли эффект или это артефакт конкретных параме��ров
- Спека: `docs/ROBUSTNESS_CHECK.md`
