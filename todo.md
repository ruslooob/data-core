## Модели и аналитика

### Автоматический поиск аномалий (P1, киллер-фича №2)
- Три уровня: одна акция, сопоставление с другими активами, поиск неизвестных событий
- Пример 1: CAR вышел за 95% ДИ + объём вырос в 2 раза → значимая аномалия
- Пример 2: сканируем весь ряд котировок, находим дни с аномальной доходностью без известного события → «что тут произошло?»
- Подробнее: `docs/ANOMALY_DETECTION.md`

### Бэктест торговых стратегий на исторических данных (P1, киллер-фича №3)
Прогон произвольных торговых стратегий на полной истории котировок с расчётом метрик (P&L, max drawdown, Sharpe, win rate). Стратегии — общие, не обязательно завязанные на event study. Цель: пользователь находит закономерность через графики/event study/anomaly detection и проверяет её как реальную стратегию.

Примеры стратегий для MVP:
- **buy & hold** — дефолтная база для сравнения
- **следовать рынку** — пассивно повторять IMOEX
- **только золото** — защитный актив
- **вклад / ОФЗ** — безрисковая доходность как baseline
- **аномальный объём в сторону рынка** — покупать при необычно высоком объёме, направление совпадает с движением рынка
- **нейросеть-предсказатель** *(концепт)* — модель, обученная на исторических прецедентах, выдаёт прогноз будущей цены

Требования:
- Виджет «Backtest» с выбором стратегии, набора активов, периода, начального капитала
- Backend исполняет стратегию пошагово по историческому ряду, ведёт портфель
- Результат: equity curve, метрики, сделки
- Сравнение нескольких стратегий бок-о-бок (несколько backtest виджетов в одной группе?)

### Калибровка оценочного периода (P1, киллер-фича №1)
- Фильтрация выбросов в оценочном окне перед калибровкой модели (например, ±3σ от mean)
- Долгое оценочное окно накапливает шумные дни — модель должна учиться на нормальном поведении
- Параметр в API event study + новая опция в виджете
- Цель: более точный baseline → более чистый CAR

## Визуализация

### Стакинг графиков
- Возможность ставить несколько графиков друг под другом для сравнения
- Например: график акции + индекс Мосбиржи + другой актив
- Требует рефакторинга кода построения графиков

### Расширенное окно на графике
- Показывать не только событийное окно, но и контекст до/после — чтобы видеть всю картину

### Лассо (концепт)
- Выделение области на графике мышкой → показ статистики по выделенному участку (CAR, объём, даты)
