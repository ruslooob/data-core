## Пределы UI / запросы аналитика


Запросы, которые пришлось делать в обход UI (через SQL + API напрямую) — это и есть
сценарии, которые сейчас в UI неудобны или невозможны:

1. **Фильтр по `payload`-полю в один клик.** Для разбора `CB_RATE_DECISION` по `direction`
   (hike/cut/hold) пришлось руками писать SQL. В UI `Поиск прецедентов` есть только
   PQL-фасад, но даже там надо знать схему `tagged_events` + JSON-доступ. Хочется
   form-фильтр «тег → доступные payload-поля → значения», прямо в виджете.

2. **Бок-о-бок сравнение двух выборок.** Подразрезы (pre-2022 vs post-2022, низкие vs
   высокие дивиденды) хотелось бы видеть в одном виджете как две колонки CAR-распределений.
