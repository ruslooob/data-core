# Журнал поиска аномалий

Этот файл — рабочий журнал поиска аномалий через PQL. Цель — найти паттерны, которые потом можно превратить в стратегию (см. [BACKTEST_STRATEGIES.md](BACKTEST_STRATEGIES.md)).

Цикл:
1. Сформулировать гипотезу: «такой-то тип события на таких-то тикерах вызывает такую-то аномальную реакцию».
2. Написать PQL-запрос (через виджет редактора прецедентов или напрямую через `POST /api/precedents/search`).
3. Записать результат в раздел «Гипотезы»: количество найденных событий, распределение метрики, важные кейсы.
4. Сделать вывод: устойчив ли паттерн, и можно ли превратить его в trigger-rule стратегии.

Если паттерн устойчив (повторяется на разных тикерах/периодах, имеет значимый размер эффекта) — переходим в `BACKTEST_STRATEGIES.md` и формулируем стратегию.

## Доступные функции и таблицы

**TA/PQL-функции** (PL/Python в Postgres):
- `car(ticker, event_date, model='market_model', window_before=5, window_after=5, estimation=200, outlier_threshold=NULL, max_date=NULL)` — накопленная аномальная доходность.
- `vol_ratio(ticker, event_date, window_before=5, window_after=5, max_date=NULL)` — отношение std доходностей после/до события.
- `volume_ratio(ticker, event_date, window_before=5, window_after=5, max_date=NULL)` — отношение средних объёмов после/до.

Подробности — [SPEC_PRECEDENT_LANGUAGE.md](SPEC_PRECEDENT_LANGUAGE.md), модели CAR — [EXPECTED_RETURN_MODELS.md](EXPECTED_RETURN_MODELS.md).

**Persistent-таблицы:**
- `tagged_events(event_id, event_date, announce_date, event, payload, tag, tag_name, tag_type)` — события с тегами.
- `tags(code, name, type)` — справочник тегов (`type`: `company`, `topic`, `sector`).
- `events(...)`, `event_tags(...)` — нормализованная схема под VIEW `tagged_events`.
- `stocks`, `stock_candles`, `risk_free_rate`, `dividends` — рыночные данные (для UDF, обычно не дёргаем напрямую).

## Валидные шаблоны

### Многофакторная оценка аномальности

```sql
WITH scored AS (
  SELECT te.event_date, te.event, te.tag AS ticker,
         CASE WHEN ABS(car(te.tag, te.event_date)) > 0.05 THEN 1 ELSE 0 END
       + CASE WHEN volume_ratio(te.tag, te.event_date) > 2.0 THEN 1 ELSE 0 END
       + CASE WHEN vol_ratio(te.tag, te.event_date) > 2.0    THEN 1 ELSE 0 END
         AS score
  FROM tagged_events te
  JOIN tags t ON t.code = te.tag AND t.type = 'company'
)
SELECT event_date, event, ticker, score
FROM scored
WHERE score >= 2
ORDER BY score DESC, event_date DESC
LIMIT 20;
```

### CAR на event-study со ссылкой на topic-тег

```sql
SELECT te.event_date, te.event,
       car(te.tag, te.event_date) AS car
FROM tagged_events te
JOIN tagged_events te2 ON te2.event_id = te.event_id
JOIN tags t ON t.code = te.tag AND t.type = 'company'
WHERE te2.tag = 'DIVIDEND_ANNOUNCEMENT'
ORDER BY ABS(car(te.tag, te.event_date)) DESC
LIMIT 20;
```

### Pre-event utечка (CAR до t=0)

```sql
SELECT te.event_date, te.event, te.tag AS ticker,
       car(te.tag, te.event_date, window_after => -1) AS car_pre
FROM tagged_events te
JOIN tags t ON t.code = te.tag AND t.type = 'company'
WHERE ABS(car(te.tag, te.event_date, window_after => -1)) > 0.03
ORDER BY ABS(car(te.tag, te.event_date, window_after => -1)) DESC
LIMIT 30;
```

## Гипотезы и проверки

> **Имя гипотезы:** `A_<семья>_<член>_КОД`. `A` — журнал аномалий (у стратегий — `S`). `<семья>` — тема в порядке появления, `<член>` — конкретная гипотеза внутри темы. `КОД` — короткий человекочитаемый суффикс (UPPER_SNAKE): объект + событие + метрика; у первого члена семьи код полный и задаёт тему (`A_1_1_LKOH_DIV_ANNOUNCE_CAR`), у следующих — дельта от него, если читаемость не страдает (`A_1_2_ABS_CAR`).
>
> **Структура записи:** Гипотеза → Что проверено (выборка, точка t=0, окна, модели, выбросы) → Результат → Вывод → Связь со стратегией → Что дальше. Секция «Что дальше» обязательна: одним знаковым прогоном вопрос не закрывается (нулевое среднее CAR совместимо как с отсутствием реакции, так и с реакцией непостоянного направления), поэтому каждая гипотеза порождает следующие.

### A_1_1_LKOH_DIV_ANNOUNCE_CAR — направленная реакция на объявление дивидендов LKOH

**Гипотеза.** После объявления дивидендов по LKOH цена показывает аномальную доходность (CAR) — рынок реагирует на новость о размере выплаты.

**Что проверено**:

- *Выборка.* 40 объявлений дивидендов LKOH за 2000–2025. Пригодны 37: у трёх самых ранних (2000, 2001, 2002) нет полного оценочного окна — котировки LKOH в базе начинаются с 2002-01-08, и `car()` для них возвращает NULL.
- *Точка t=0.* Дата объявления. Для этих событий она совпадает с `announce_date`; отсечка и сама выплата — отдельные события (тег `DIVIDEND_PAYMENT`) и в выборку не входят, поэтому эффект объявления не смешивается с эффектом отсечки.
- *Окна.* Восемь окон вокруг t0: предсобытийное `[-5,-1]`, день объявления `[0,0]`, немедленная реакция `[0,+1]`, `[0,+5]`, пост-окно без дня объявления `[+1,+5]`, симметричное `[-5,+5]` (как в прежнем отчёте), длинные `[0,+10]` и `[0,+20]`.
- *Модели.* market_model и capm — результат сверен на обеих.
- *Выбросы.* Прогон без фильтра и с σ-фильтром (2.5 и 3.0): проверка, не держится ли средний на нескольких экстремумах.
- *Качество замера.* События с плохо обученной моделью отсеиваются — там, где рынок (IMOEX) объясняет на оценочном окне меньше 10% дисперсии доходностей LKOH (R² < 0.10): «норма» для них построена по сути на шуме. Таких 2, оба 2025 года — рыночный ряд IMOEX в базе обрывается на 2025-09-15, поэтому их окна частично попадают на период без рынка (битый замер, а не крупное движение цены — отсев законен). Их удаление вердикт не меняет: средние лишь подъезжают ближе к нулю, t-статистики и отношение `|CAR|` к норме — прежние. Эти два события станут измеримыми после догрузки IMOEX.

**Результат** (market_model; capm даёт то же самое):

| Окно | n | Mean CAR | t-стат. | Положит. |
|---|---:|---:|---:|---:|
| `[-5,-1]` до объявления | 37 | +0.35% | +0.71 | 18/37 |
| `[0,0]` день объявления | 37 | −0.08% | −0.42 | 17/37 |
| `[0,+1]` реакция | 37 | −0.09% | −0.36 | 19/37 |
| `[0,+5]` | 37 | −0.07% | −0.14 | 18/37 |
| `[+1,+5]` без дня t0 | 37 | +0.01% | +0.03 | 21/37 |
| `[-5,+5]` симметричное | 37 | +0.30% | +0.42 | 18/37 |
| `[0,+10]` | 37 | −0.56% | −0.78 | 16/37 |
| `[0,+20]` | 37 | +0.22% | +0.26 | 21/37 |

Как это читается:

- Во **всех** окнах `|t| < 0.8` — статистически значимого эффекта нет нигде (ориентир значимости — около `|t| ≥ 2`).
- День объявления и немедленная реакция `[0,+1]` — практически ноль (−0.08% и −0.09%). Это главный довод: будь в объявлении новость, эффект был бы виден именно здесь.
- Слабый плюс симметричного `[-5,+5]` (+0.30%) набирается **предсобытийным** окном `[-5,-1]`, а не реакцией на объявление: пост-окна около нуля или в минусе.
- Доля положительных CAR около половины в каждом окне; плюсы и минусы по величине симметричны (максимумы +7.4% и +4.9%, минимумы −6.3%, −6.2%, −6.2%) и гасят друг друга. Фильтр выбросов почти не двигает среднее — значит, дело не в паре аномальных дней, а в том, что распределение само центрировано около нуля.

**Вывод A_1_1: отвергнута, надёжно.** Аномальной реакции на объявление дивидендов LKOH нет ни в одном окне, ни в одной модели, ни с фильтром выбросов, ни без него. Экономическая причина — дивидендная политика LKOH стабильна и заранее известна рынку: к моменту официального объявления ожидаемый размер выплаты уже заложен в цену (прогнозы аналитиков, прежние ориентиры компании), сюрприза нет — нет и аномальной доходности. Это нормальное поведение эффективного рынка для предсказуемой новости.

**Связь со стратегией.** Сигнала нет — для стратегии не годится, ветка тупиковая. При этом гипотеза «дивиденды → рост» не закрыта в принципе: её живой вариант — A4 (объявления по всем компаниям, не только LKOH), где на большой выборке эффект уже значим.

**Что дальше.** Среднее CAR ≈ 0 не отличает «реакции нет» от «реакция есть, но разнонаправленная и гасится при усреднении». Этот вопрос вынесен в отдельную гипотезу **A_1_2_ABS_CAR** — проверку абсолютной величины реакции.

**Воспроизведение** (PQL; окно подставляется в `window_before`/`window_after`):

```sql
WITH ev AS (
  SELECT te.event_date AS d
  FROM tagged_events te
  JOIN tagged_events te2 ON te2.event_id = te.event_id
  WHERE te.tag = 'LKOH' AND te2.tag = 'DIVIDEND_ANNOUNCEMENT'
), c AS (
  SELECT car('LKOH', d, window_before => 0, window_after => 5) AS car FROM ev
)
SELECT COUNT(*) FILTER (WHERE car IS NOT NULL) AS n,
       AVG(car) AS mean, STDDEV(car) AS std,
       COUNT(*) FILTER (WHERE car > 0) AS positive
FROM c;
```

### A_1_2_ABS_CAR — абсолютная реакция (величина |CAR|) на то же объявление

Продолжение A_1_1 на той же выборке. Там среднее CAR оказалось нулевым, но это совместимо с двумя разными мирами: реакции нет вовсе — либо она есть, но её знак непостоянен от события к событию, и плюсы с минусами гасятся при усреднении. Знаковое среднее их не различает.

**Гипотеза.** Реакция на объявление существует по величине, даже если знак непостоянен: абсолютное отклонение цены от нормы `|CAR|` превышает обычный рыночный шум.

**Что проверено.** Та же выборка — 37 объявлений дивидендов LKOH, market_model. Метрика — средний `|CAR|` в окне события против разброса, который норма даёт сама по себе: для распределения с нулевым средним ожидаемый `|CAR| ≈ σ·√(2/π)`. Новый инструмент не нужен — норму считает та же модель ожидаемой доходности, что и для обычного CAR. Окна — те же восемь, что в A_1_1: `[-5,-1]`, `[0,0]`, `[0,+1]`, `[0,+5]`, `[+1,+5]`, `[-5,+5]`, `[0,+10]`, `[0,+20]`.

**Результат.**

| Окно | mean \|CAR\| | разброс нормы (σ·√(2/π)) | отношение |
|---|---:|---:|---:|
| `[-5,-1]` | 2.12% | 2.38% | 0.89 |
| `[0,0]` | 0.84% | 0.86% | 0.98 |
| `[0,+1]` | 1.16% | 1.16% | 1.00 |
| `[0,+5]` | 2.34% | 2.47% | 0.95 |
| `[+1,+5]` | 1.97% | 2.01% | 0.98 |
| `[-5,+5]` | 3.46% | 3.44% | 1.01 |
| `[0,+10]` | 3.22% | 3.47% | 0.93 |
| `[0,+20]` | 3.69% | 4.08% | 0.90 |

**Вывод A_1_2: отвергнута.** Отношение ≈ 1 во всех окнах — абсолютное движение цены вокруг объявления равно обычному шуму, событие не двигает цену сильнее нормы ни в какую сторону. Значит, нулевое среднее в A_1_1 — это именно отсутствие реакции, а не замаскированная разнонаправленная. Пара A_1_1 + A_1_2 закрывает тему «LKOH реагирует на объявление дивидендов» полностью: ни по знаку, ни по модулю.

**Связь со стратегией.** Сигнала нет — для стратегии не годится.

**Что дальше.** Направленная реакция, условная по знаку сюрприза (дивиденд выше или ниже ожидаемого), — самостоятельная будущая гипотеза, не продолжение A_1.

**Воспроизведение** (PQL):

```sql
WITH ev AS (
  SELECT te.event_date AS d
  FROM tagged_events te
  JOIN tagged_events te2 ON te2.event_id = te.event_id
  WHERE te.tag = 'LKOH' AND te2.tag = 'DIVIDEND_ANNOUNCEMENT'
), c AS (
  SELECT car('LKOH', d, window_before => 0, window_after => 5) AS car FROM ev
)
SELECT COUNT(car) AS n,
       AVG(ABS(car)) AS mean_abs_car,
       STDDEV(car) AS std,
       AVG(ABS(car)) / (STDDEV(car) * SQRT(2.0 / PI())) AS ratio
FROM c;
```

### A_1_3_VOL_REACTION — реакция дисперсии и объёма на то же объявление

Третий срез той же темы. A_1_1 показал, что цена в среднем не сдвигается, A_1_2 — что движения нет и по модулю. Остаётся вопрос: может, объявление меняет не уровень цены, а её **разброс** — снимает неопределённость (тогда волатильность после события падает) или, наоборот, добавляет (расхождение мнений, ребаланс → растёт).

**Гипотеза.** Вокруг объявления меняется волатильность и/или объём торгов LKOH — даже если средняя цена не реагирует.

**Что проверено.** Метрики `vol_ratio` (во сколько раз волатильность после события выше, чем до него) и `volume_ratio` (то же для объёма торгов) — на окнах 5/5, 10/10 и 20/20. Это дальности ±5, ±10, ±20, аналогичные окнам A_1_1 и A_1_2; одно-сторонние окна типа `[0,+5]` к отношению «после/до» не приводятся по построению — ему нужны и кусок до, и кусок после события.

Сами эти числа без точки отсчёта ничего не значат, поэтому берём **контрольную группу** — 500 случайных торговых дат LKOH, в которые ничего не объявляли, и считаем на них те же метрики. Если в дни объявлений метрики ведут себя как в этом «фоне обычного дня», реакции нет.

Одна тонкость, которую снимает контроль: `vol_ratio` — это отношение, и его *среднее* само по себе оказывается выше 1, даже когда никакой реакции нет (вниз отношение ограничено нулём, вверх — нет, поэтому редкие большие значения перетягивают среднее). Честный центр здесь — медиана, а не среднее; и контрольная группа обычных дней даёт ровно тот же перекос — с ним мы и сравниваем события.

Различие распределений проверяем **ранговым тестом** (тест Манна–Уитни: сравнивает две выборки по порядку значений, не предполагая нормальности). Его результат — `p`: большое (≥ 0.05) значит «выборки неразличимы», маленькое — есть реальное различие.

**Результат** (контроль N = 500, один и тот же seed по всем окнам):

| Метрика | окно | событие (медиана) | контроль (медиана) | p (ранговый тест) |
|---|---|---:|---:|---:|
| vol_ratio | 5/5 | 1.004 | 1.002 | 0.70 |
| vol_ratio | 10/10 | 1.132 | 0.993 | 0.26 |
| vol_ratio | 20/20 | 1.088 | 0.981 | 0.25 |
| volume_ratio | 5/5 | 0.965 | 1.002 | 0.64 |
| volume_ratio | 10/10 | 0.971 | 1.002 | 0.48 |
| volume_ratio | 20/20 | 0.953 | 0.990 | 0.39 |

*Методический след.* В первом прогоне контроль был N = 120, и на `vol_ratio` 10/10 случайно выпал низкий медианный фон (0.87) — это дало пограничный `p` = 0.038. Перепроверка с N = 500 показала, что при маленькой контрольной выборке медиана сильно гуляет (0.87 → 0.99), и пограничный результат оказался артефактом малого контроля, а не реакцией. Урок на будущее — пограничный `p` всегда проверять бóльшим N, иначе можно объявить шум сигналом.

**Вывод A_1_3: отвергнута.** Ни по волатильности, ни по объёму события статистически не отличаются от обычных дней — все шесть `p` лежат в диапазоне 0.25–0.70. Заодно развеян ложный «намёк»: у событий средний `vol_ratio` = 1.48 выглядел как рост волатильности, но это та самая завышенность среднего отношения (см. выше) — на случайных днях оно тоже ≈ 1.3, а медианы у событий и контроля при N = 500 практически совпадают (1.004 против 1.002 на 5/5). Без контрольной группы шум приняли бы за сигнал.

**Связь со стратегией.** Сигнала нет.

**Что дальше.** Группа A_1 закрыта со всех трёх сторон — знак, модуль, дисперсия: объявление дивидендов LKOH для рынка является «не-событием». Дальнейшее углубление по дивидендам — либо на других событиях их жизненного цикла (отсечка/выплата — требует даты закрытия реестра, которой пока нет в данных), либо на кросс-секции по тикерам и секторам.

**Воспроизведение.** `vol_ratio` / `volume_ratio` доступны как UDF в PQL; контрольная выборка случайных дат и ранговый тест (Манн–Уитни) считаются во внешнем скрипте (в PQL — только сами метрики).

### A2 — Скачок объёма (volume_ratio > 2) предсказывает положительный post-event CAR

> Гипотеза: события со значимым всплеском объёма (volume_ratio > 2) на следующие 5 торговых дней показывают положительный CAR — momentum-сигнал. Большой объём = сильное движение, и это движение продолжается.

**PQL-запрос (агрегаты):**
```sql
WITH spikes AS (
  SELECT car(te.tag, te.event_date, window_before => -1, window_after => 5) AS car_post
  FROM tagged_events te
  JOIN tags t ON t.code = te.tag AND t.type = 'company'
  WHERE volume_ratio(te.tag, te.event_date) > 2.0
)
SELECT COUNT(*) FILTER (WHERE car_post IS NOT NULL) AS n,
       AVG(car_post), STDDEV(car_post), ...
FROM spikes;
```

**Результаты:**

| n | Mean CAR | Std | % positive | strong_pos (>3%) | strong_neg (<-3%) |
|---:|---:|---:|---:|---:|---:|
| 118 | **+1.69%** | 6.70% | **60%** | 43 | 29 |

T-статистика: 1.69 / (6.70/√118) ≈ **2.74 — значимо** (>2.0).

Top-5 максимальных post-event CAR:
- 2017-04-12 GCHE (объявление див.) vol_x=4.23, car_post=+22.7%
- 2023-05-18 LSRG (объявление див.) vol_x=6.19, car_post=+17.4%
- 2023-07-26 TRMK (объявление див.) vol_x=3.23, car_post=+17.4%
- 2022-08-30 GAZP (объявление див.) vol_x=4.30, car_post=+16.7%
- 2022-05-17 MTSS (объявление див.) vol_x=3.45, car_post=+14.5%

**Вывод A2:** **подтвердилась.** Volume-spike в день события — устойчивый сигнал положительного движения в следующие 5 дней. Top-5 показывает что это **в основном дивидендные объявления с пробоем объёма** — то есть объём подтверждает силу позитивной новости.

**Связь со стратегией:** trigger «купить на день volume-spike (любого company-events), держать 5 дней». Это **новая гипотеза для `BACKTEST_STRATEGIES.md` — H16**.

⚠ Caveat: top-5 — это все дивидендные объявления. Может, A2 — просто маска для A4 («дивидендные объявления → +CAR»). Стоит сравнить эффекты после фильтра «без DIVIDEND_ANNOUNCEMENT в te2».

### A3 — Pre-event «утечка»: значимый |CAR| до t=0

> Гипотеза: для скольких events движение цены **до** события превышает 3%? Если много — это либо инсайдерская торговля, либо рынок предсказуемо реагирует на ожидаемые события.
>
> Окно: `window_after = -1` означает только до события, без самого дня.

**Результаты:**

| n | Mean abs CAR_pre | leak >3% | leak >5% | leak up >3% | leak down >3% |
|---:|---:|---:|---:|---:|---:|
| 1754 | **3.28%** | **711** (40%) | 339 (19%) | 282 | **429** |

Top-5 максимальных |CAR_pre|:
- 2022-03-30 IRAO (объявление див. 0.24 ₽): −80.67%
- 2025-01-08 TATNP (выплата 17.39 ₽): −44.19%
- 2025-01-08 TATN (выплата 17.39 ₽): −40.43%
- 2019-04-22 NKNCP (выплата 19.94 ₽): −36.14%
- 2008-05-21 PLZL (объявление 0.29 ₽): +31.37%

**Вывод A3:** **подтверждено наполовину.** Pre-event движение действительно широко распространено — 40% событий имеют |CAR| > 3% за 5 дней до. Но **направление преимущественно негативное** (leak_down 429 vs leak_up 282), что противоречит «инсайдерская торговля = positive front-running».

Top-5 — экстремальные случаи (-80%, -44%, -40%) — это шоковые события (санкции 2022 для IRAO, выплата TATN после провала, и т.п.). Их CAR-кейсы загрязнены **самим шоком**, не утечкой инсайда. **Чистый инсайдерский паттерн отдельно не вычленяется** без выкидывания outliers.

**Связь со стратегией:** trigger «sell за 5 дней до события, если |CAR_pre| уже > 3%» — реализуем не получится без знания будущей даты события (lookahead). Это **диагностический паттерн**, не торговый.

### A4 — Дивидендные объявления (любая компания) дают значимый положительный CAR

> Гипотеза: расширенная версия A1 на все компании. Если на большой выборке средний CAR положительный — паттерн универсальный, его можно превратить в стратегию.

**Результаты:**

| n | Mean CAR | Std | % positive | strong_pos (>3%) | strong_neg (<-3%) |
|---:|---:|---:|---:|---:|---:|
| **886** | **+0.84%** | 7.15% | 54% | **261** | 203 |

T-статистика: 0.84 / (7.15/√886) ≈ **3.5 — высоко значимо**.

Top-5 максимальных CAR (вся выборка):
- 2019-03-11 NKNCP: +53.66%
- 2021-03-12 TRMK: +40.79%
- 2021-07-30 TRMK: +35.81%
- 2019-03-11 NKNC: +30.78%
- 2021-08-20 RASP: +28.85%

**Вывод A4:** **подтвердилась.** На выборке 886 событий средний CAR после дивидендных объявлений — **+0.84%** при std 7.15%. T-stat ≈ 3.5 — устойчиво значимо. Асимметрия в пользу роста: 261 strong-up vs 203 strong-down.

Top-5 — компании 2-эшелона (NKNCP, TRMK, RASP) с экстремальными +30..+50% — это малоликвидные тикеры с большой волатильностью. Эффект на больших именах (LKOH, GAZP, SBER) меньше, но в среднем — положительный.

**Связь со стратегией:** trigger «купить на день DIVIDEND_ANNOUNCEMENT (любая компания), держать 5–10 дней» — кандидат в **H17 для `BACKTEST_STRATEGIES.md`**. Размер эффекта (+0.84% за 5 дней = ~40% годовых на бумаге, но это для каждой сделки отдельно; в портфеле эффект надо считать через бэктест).

### A_5_1_DIV_ANNOUNCE_BY_SECTOR — реакция на объявление дивидендов: кросс-секция по тикерам и секторам

A_1 показал отсутствие реакции у LKOH. Вопрос: это особенность LKOH или общее свойство — и где тогда живёт положительный эффект, найденный в A4 на пуле всех компаний (+0.84%)?

**Гипотеза.** Направленная реакция на объявление дивидендов различается по тикерам и секторам: у одних компаний она есть, у других нет.

**Что проверено.** 30 ликвидных тикеров в 8 секторах (принадлежность задана вручную — в данных секторного признака нет). По каждому тикеру — направленный CAR (market_model) в окнах `[0,+1]` и `[0,+5]` по каждому событию объявления, затем пул по сектору. Отсечка `event_date ≤ 2025-09-01` (рыночный ряд IMOEX обрывается 2025-09-15). Деление по тикерам важно из-за мощности: на ~30 событиях один тикер не различает эффект меньше ~1.4%, а пул сектора (n≈50–200) различает.

**Результат (пулы по секторам).**

| Сектор | n | CAR [0,+5] | t | CAR [0,+1] | t |
|---|---:|---:|---:|---:|---:|
| Нефть | 193 | −0.16% | −0.44 | +0.12% | +0.49 |
| Газ | 53 | +1.29% | +1.83 | +1.04% | +1.50 |
| Металлы/горн. | 194 | −0.18% | −0.62 | −0.04% | −0.18 |
| Банки/финансы | 48 | +0.96% | +1.24 | +0.69% | +1.38 |
| **Телеком** | 76 | **+1.22%** | **+2.81** | **+1.30%** | **+3.68** |
| Химия | 75 | +0.54% | +0.52 | +1.15% | +1.25 |
| Энергетика | 51 | +0.29% | +0.45 | +0.20% | +0.33 |
| Потреб. | 62 | +0.61% | +0.83 | +0.45% | +1.01 |
| Все | 752 | +0.31% | +1.62 | +0.44% | +2.88 |

Внутри нефти все тикеры по отдельности незначимы (LKOH −0.12%/t−0.24, ROSN ≈0, SIBN +0.31%/t0.40, TATN −0.32%, TATNP −0.14%, SNGSP −0.84%/t−0.66). В телекоме сигнал концентрируется в Ростелекоме: RTKMP +2.00%/t2.27 (`[0,+5]`) и +2.02%/t3.22 (`[0,+1]`), RTKM +1.54%/t2.39 (`[0,+1]`); MTSS слабо положителен.

**Вывод A_5_1.** Три факта:

1. **Отсутствие реакции — свойство всего нефтяного сектора, а не особенность LKOH** (пул нефти −0.16%, t−0.44; каждый нефтяник по отдельности незначим). A_1 подтверждается на расширенной выборке.
2. **Единственный устойчивый положительный сигнал — телеком, внутри него Ростелеком.** На окне `[0,+1]` пул телекома t=3.68 (p≈0.0002) переживает поправку на множественность (8 секторов × 2 окна = 16 тестов, Bonferroni-порог ≈0.003); на `[0,+5]` (t2.81) — на грани. Положительные намёки в газе и банках (t≈1.2–1.8) поправку не переживают — это шум.
3. **Эффект A4 (+0.84%) завышен неликвидом.** На 30 ликвидных именах общий пул лишь +0.31% (`[0,+5]`, t1.62): A4 раздували малоликвидные тикеры 2-го эшелона с экстремальными движениями.

Осторожность: пул сектора суммирует коррелированные события (RTKM и RTKMP — одна компания; объявления в одну дату у разных тикеров), поэтому пуловые t-статистики оптимистичны — чище поштучный RTKMP (t3.22).

Каузально это укладывается в вывод A_1: реакция возникает там, где дивиденд **менее предсказуем** (госкомпания Ростелеком с нестабильной выплатой), и отсутствует у стабильных, заранее анонсированных плательщиков (нефтемейджоры). Эффект сидит в сюрпризе, а не в самом факте дивиденда.

**Связь со стратегией.** Кандидат — «купить на объявление дивидендов Ростелекома (особенно RTKMP), держать 1–5 дней». Перед оформлением в `S<N>` — проверить на бэктесте и убедиться, что RTKM/RTKMP не дублируют один сигнал.

**Что дальше — A_5_2.** Проверить механизм напрямую: обусловить реакцию **предсказуемостью выплаты** (стабильные плательщики против скачущих). Это отложенный «сюрприз» из A_1, теперь подкреплённый кросс-секцией: где выплата предсказуема — реакции нет, где нет — есть.

## Сводный вывод

Итоги проверок:
- **A_1_1 + A_1_2 + A_1_3** (LKOH, объявление дивидендов) — отвергнуты: реакции нет ни по знаку CAR (A_1_1), ни по модулю |CAR| (A_1_2), ни по дисперсии/объёму (A_1_3 — событие неотличимо от случайной даты). Тема закрыта.
- **A_5_1** (кросс-секция по секторам) — отсутствие реакции общее для всей нефти (не особенность LKOH); единственный устойчивый сигнал — телеком/Ростелеком (RTKMP, t3.2 на `[0,+1]`); эффект A4 завышен неликвидом. Каузально: реакция там, где дивиденд непредсказуем.

- **A3** (pre-event утечка) — присутствует, но загрязнена шоковыми событиями; не торгуема.
- **A4** (все дивидендные объявления → +CAR) — подтверждена надёжно, t-stat 3.5.

Два подтверждённых паттерна → две новые гипотезы стратегий: **H16 (volume-spike momentum)** и **H17 (dividend announcement buy)**. Они идут в очередь `BACKTEST_STRATEGIES.md`.

## Связь со стратегиями

Найденная аномалия становится trigger-правилом стратегии так:
1. PQL-запрос аномалии возвращает множество `(ticker, event_date)`.
2. В trigger-rule стратегии повторяем то же условие, но как **фильтр на текущем тике** — `WHERE EXISTS (... AND te.event_date = :tick - N)`.
3. Action — buy/sell с заданным размером и priority.
4. Прогоняем на всей истории, смотрим что доходность статегии лучше пассивного бенчмарка.

Это путь от «нашёл паттерн в данных» к «использую его как сигнал». Каждая подтверждённая гипотеза в этом файле — кандидат на новую гипотезу `S<N>` в `BACKTEST_STRATEGIES.md`.
