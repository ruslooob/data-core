# Ограничения Dash/Plotly для Stock Viewer

Попытка создать терминало-подобный stock viewer в nb23 (март 2026). Базовая функциональность работает, но UX упирается в архитектурные ограничения Dash.

## 1. Rangeslider блокирует автоскейл Y

Когда `rangeslider` включён, Plotly фиксирует Y-ось по min/max **всех** данных (за все 20 лет), а не по видимому окну. При навигации слайдером по X — линия цены «сплющена» на фоне полного диапазона.

**Пробовали:** `autorange=True`, `fixedrange=False`, вычисление Y range вручную по видимому X при построении. Начальный вид корректный, но при скролле слайдером Y не обновляется — ограничение на уровне Plotly.js.

**В терминалах:** клиентский JS пересчитывает Y range на каждый кадр — невозможно в серверной модели Dash.

## 2. Невозможность overlapping panels

В терминалах объём рисуется поверх ценового графика (полупрозрачный area chart в нижних 15-20%). В Plotly subplot-ы (`make_subplots`) не перекрываются — каждый имеет свой непересекающийся `domain`.

**Пробовали:**
- `overlaying='y'` — масштабы цены (тысячи) и объёма (миллионы) несовместимы
- Ручные пересекающиеся `domain`-ы — Plotly не поддерживает корректный рендеринг с автоскейлом

**В терминалах:** Lightweight Charts имеет встроенные panes с перекрытием и независимыми осями Y.

## 3. Серверный round-trip на каждое действие

Dash — серверный фреймворк. Каждый callback — HTTP-запрос → Python → JSON обратно. Для 6000+ точек — ~100-300мс задержки. Плавная навигация (drag, pinch-zoom, scroll) невозможна.

**В терминалах:** данные на клиенте, все операции в браузере без серверных запросов.

## 4. Баг Plotly: add_vline + datetime + annotation

`fig.add_vline(x=pd.Timestamp(...), annotation_text='t=0')` → `TypeError`. Внутренний код Plotly вызывает `sum([timestamp])`. Обходной путь: `add_shape` + `add_annotation` вместо `add_vline`.

## Вывод

Dash/Plotly подходит для аналитических дашбордов с кнопками и расчётами. Для интерактивного stock viewer с плавной навигацией, автоскейлом Y и overlapping panels нужен клиентский JS.

**Рекомендация:** Lightweight Charts (open source, TradingView) — встроенный автоскейл Y, panes с перекрытием, rangeslider, crosshair, свечные графики.
