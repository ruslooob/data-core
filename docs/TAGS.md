# Система тегов событий

## Идея

Событие в реальном мире — текст: «6-й пакет санкций ЕС против России: эмбарго на нефть, отключение банков от SWIFT». Чтобы такие записи участвовали в SQL-запросах наравне со структурированными данными, событию нужно дать машиночитаемую разметку. Это и делают **теги**.

Тег — атомарный признак события: страна (`RUS`), компания (`LKOH`), тема (`SANCTIONS`), отрасль (`ENERGY`), актив (`OIL`). Одно событие получает столько тегов, сколько нужно, чтобы по нему было удобно искать. Связь — many-to-many: один тег у многих событий, у одного события много тегов.

Подход тегирования также известен как **feature extraction**: из неструктурированного текста выделяются признаки, по которым потом ведётся поиск, фильтрация и агрегация. В нашем проекте feature extraction развит слабо и не находится в приоритете: разметка ведётся вручную либо парсерами под конкретные типы событий (страны через NER, авиакатастрофы по шаблону). Полноценный пайплайн автоматической разметки — задача будущей итерации.

## Типы тегов

У каждого тега есть `type` — крупная категория, по которой удобно фильтровать («только компании», «только страны»). Текущая разметка использует три типа:

- `company` — публичные компании-эмитенты (`LKOH`, `SBER`, `GAZP`, ...).
- `country` — государства и юрисдикции (`RUS`, `USA`, ...).
- `topic` — тема события (`DIVIDEND_ANNOUNCEMENT`, `DIVIDEND_PAYMENT`, ...).

Целевая классификация шире и предполагает деление на три верхних уровня:

```
actor      — кто действует или кого затрагивает (country, organization, company, person, region)
event      — что произошло (topic, policy, crisis)
context    — контекст события (asset, sector, metric)
```

Полная иерархия — направление расширения; в реальной БД пока присутствует только подмножество.

## Примеры разметки

### Объявление дивидендов LKOH
```
event: «Объявление дивидендов LKOH 85 руб/акция»
tags:  LKOH (company), DIVIDEND_ANNOUNCEMENT (topic)
```

### Санкционный пакет ЕС
```
event: «6-й пакет санкций ЕС: эмбарго на нефть, отключение банков от SWIFT»
tags:  RUS (country), SANCTIONS (topic), EU (planned: organization), OIL (planned: asset)
```

«planned» здесь означает: тег относится к целевой иерархии, в текущей разметке такого типа нет.
